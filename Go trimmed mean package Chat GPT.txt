## 📘 2. What is a Trimmed Mean?

A **trimmed mean** is a **robust measure of central tendency** that reduces the influence of outliers.

### **Definition**
A trimmed mean removes a certain percentage of the **lowest and highest values** before computing the mean.

### **Example**
Say we have:
```
data = [2, 3, 5, 7, 100]
```
A **20% trimmed mean** trims 20% from each end (1 value from each side):
```
Remaining values = [3, 5, 7]
Mean = (3 + 5 + 7) / 3 = 5.0
```
This result (5.0) is much more **robust** to the extreme outlier (100) than the regular mean (23.4).

### **Symmetric vs. Asymmetric Trimming**
- **Symmetric trimming**: remove the same proportion from both ends (e.g., 5% from each side).
- **Asymmetric trimming**: remove **different** proportions from the lower and upper tails (e.g., 10% from the low end, 20% from the high end).

```go
package trimmedmean

import (
	"errors"
	"sort"
)

// TrimmedMean computes the symmetric or asymmetric trimmed mean of a slice of float64 values.
// If only one trim proportion is provided, symmetric trimming is assumed.
func TrimmedMean(data []float64, trims ...float64) (float64, error) {
	if len(data) == 0 {
		return 0, errors.New("data slice cannot be empty")
	}
	sort.Float64s(data)

	var lowerTrim, upperTrim float64
	if len(trims) == 1 {
		lowerTrim, upperTrim = trims[0], trims[0]
	} else if len(trims) == 2 {
		lowerTrim, upperTrim = trims[0], trims[1]
	} else {
		return 0, errors.New("provide one (symmetric) or two (asymmetric) trim values")
	}

	n := len(data)
	low := int(float64(n) * lowerTrim)
	high := int(float64(n) * upperTrim)

	if low+high >= n {
		return 0, errors.New("trimming proportion too large")
	}

	trimmed := data[low : n-high]
	sum := 0.0
	for _, v := range trimmed {
		sum += v
	}
	return sum / float64(len(trimmed)), nil
}
```

---

## ⚖️ 1. Symmetric Trimming

### **What it is**
- You trim **the same proportion** of data from **both tails** (the lowest and highest values).  
- Example: a **5% symmetric trimmed mean** removes the lowest 5% *and* the highest 5% of the sorted dataset.

### **When to use it**
Use **symmetric trimming** when:
- Your data are **roughly symmetric** (e.g., normal or near-normal distribution).
- You expect **outliers on both sides** (high and low values) that might distort the mean equally.
- You want a **robust estimate of central tendency** but still preserve balance in the treatment of both ends.

### **Example scenario**
- Measuring average **employee salaries** in a company:  
  - Some very low or very high salaries may distort the average.
  - Symmetric trimming (e.g., 10% on each end) gives a stable, fair central value.

### **Advantages**
- Simple to explain and justify statistically.
- Works well for most **balanced, roughly symmetric distributions**.
- Directly comparable to R’s built-in `mean(x, trim = p)`.

---

## ⚖️ 2. Asymmetric Trimming

### **What it is**
- You trim **different proportions** from the **lower and upper ends** of the distribution.  
- Example: a **10%/25% asymmetric trim** removes 10% of the lowest values and 25% of the highest values.

### **When to use it**
Use **asymmetric trimming** when:
- The data are **skewed** or have **unbalanced outliers** on one side.
- You want to **reduce the influence** of outliers in one direction more than the other.
- You’re analyzing **bounded or truncated** data (e.g., scores that can’t go below zero but can have extreme highs).

### **Example scenarios**
1. **Real estate prices**:  
   - The upper tail (luxury homes) is extremely long, but the lower tail (cheap homes) is short.  
   - Use **asymmetric trimming** (e.g., 0.05 low end, 0.20 high end) to reduce high-end distortion.

2. **Reaction times in psychology**:  
   - There are often long right tails (some people react much slower), but not extreme fast outliers.  
   - Use **asymmetric trimming** to cut more from the **high** end.

3. **Income or wealth data**:  
   - High-income outliers heavily skew the mean upward.  
   - Trimming more from the upper tail gives a more representative central estimate.

### **Advantages**
- Provides a more **accurate central measure** for **skewed or heavy-tailed data**.
- More flexible for real-world datasets that aren’t symmetric.

---

## 🔍 3. Choosing Between Symmetric and Asymmetric Trimming

| Situation | Distribution Shape | Recommended Trimming | Example |
|------------|--------------------|----------------------|----------|
| Data approximately normal | Symmetric | 5%–10% each side | Test scores |
| Data skewed to the right | Asymmetric (more on right) | e.g., 0.05 low / 0.20 high | Income or sales data |
| Data skewed to the left | Asymmetric (more on left) | e.g., 0.20 low / 0.05 high | Quality defect rates |
| Data with extreme values in both tails | Symmetric | e.g., 0.10 both ends | Experimental measurements |
| Robustness needed against arbitrary outliers | Symmetric or light asymmetric | 5–20% total | Simulation results |

---

## 📈 4. Practical Tip

If you’re unsure:
1. **Start symmetric (e.g., trim = 0.05)** — it’s standard and comparable to R’s base `mean()`.
2. **Visualize your data** (e.g., histogram or boxplot).
3. If the distribution is **clearly skewed**, move to **asymmetric trimming**.

## ⚙️ 2. How to Evaluate the Distribution in Go

To automatically evaluate whether the data are symmetric or skewed, you can compute the **skewness coefficient**.

### **Skewness formula**
For a dataset \( x_1, x_2, ..., x_n \):

\[
\text{Skewness} = \frac{n}{(n-1)(n-2)} \sum \left( \frac{x_i - \bar{x}}{s} \right)^3
\]

where:
- \( \bar{x} \) = mean  
- \( s \) = standard deviation  

Interpretation:
| Skewness value | Interpretation | Suggested trimming |
|-----------------|----------------|--------------------|
| ≈ 0 | Symmetric | Symmetric trimming (equal ends) |
| > 0 | Right-skewed | Trim more from upper tail |
| < 0 | Left-skewed | Trim more from lower tail |

## 🧮 3. Implementation Plan

You can add a **function** like this to your package:

```go
package trimmedmean

import (
	"math"
)

// EvaluateDistribution analyzes skewness and recommends trimming strategy.
func EvaluateDistribution(data []float64) (skewness float64, suggestion string) {
	n := float64(len(data))
	if n < 3 {
		return 0, "Not enough data to evaluate distribution"
	}

	// Compute mean
	sum := 0.0
	for _, v := range data {
		sum += v
	}
	mean := sum / n

	// Compute standard deviation
	var sqSum float64
	for _, v := range data {
		sqSum += math.Pow(v-mean, 2)
	}
	stdDev := math.Sqrt(sqSum / (n - 1))
	if stdDev == 0 {
		return 0, "Data are constant; symmetric trimming recommended"
	}

	// Compute skewness
	var skewSum float64
	for _, v := range data {
		skewSum += math.Pow((v-mean)/stdDev, 3)
	}
	skewness = (n / ((n - 1) * (n - 2))) * skewSum

	// Suggest trimming strategy
	switch {
	case math.Abs(skewness) < 0.3:
		suggestion = "Data are approximately symmetric; symmetric trimming recommended (e.g., 0.05)."
	case skewness > 0.3:
		suggestion = "Data are right-skewed; asymmetric trimming recommended (e.g., low=0.05, high=0.15)."
	case skewness < -0.3:
		suggestion = "Data are left-skewed; asymmetric trimming recommended (e.g., low=0.15, high=0.05)."
	default:
		suggestion = "Unable to determine; consider visual inspection."
	}

	return skewness, suggestion
}
```

### 🧠 Intuition Behind These Numbers

- **Symmetric data** (e.g., normal, bell-shaped):  
  Small trimming (5–10%) protects against random noise or mild outliers.

- **Right-skewed data** (e.g., income, sales, reaction times):  
  High-end outliers inflate the mean.  
  → Trim more from the **high end**.

- **Left-skewed data** (e.g., defect rates, completion times):  
  Low-end outliers depress the mean.  
  → Trim more from the **low end**.

```go
package trimmedmean

import (
	"math"
)

type TrimRecommendation struct {
	Skewness      float64
	LowTrim       float64
	HighTrim      float64
	Recommendation string
}

// EvaluateDistribution analyzes skewness and recommends symmetric or asymmetric trimming levels.
func EvaluateDistribution(data []float64) TrimRecommendation {
	n := float64(len(data))
	if n < 3 {
		return TrimRecommendation{0, 0.05, 0.05, "Not enough data; default symmetric 5% trimming recommended."}
	}

	// Compute mean
	sum := 0.0
	for _, v := range data {
		sum += v
	}
	mean := sum / n

	// Compute standard deviation
	var sqSum float64
	for _, v := range data {
		sqSum += math.Pow(v-mean, 2)
	}
	stdDev := math.Sqrt(sqSum / (n - 1))
	if stdDev == 0 {
		return TrimRecommendation{0, 0.05, 0.05, "Data constant; symmetric trimming recommended."}
	}

	// Compute skewness
	var skewSum float64
	for _, v := range data {
		skewSum += math.Pow((v-mean)/stdDev, 3)
	}
	skewness := (n / ((n - 1) * (n - 2))) * skewSum

	rec := TrimRecommendation{Skewness: skewness}

	switch {
	case math.Abs(skewness) <= 0.3:
		rec.LowTrim, rec.HighTrim = 0.05, 0.05
		rec.Recommendation = "Data are approximately symmetric; symmetric 5% trimming suggested."
```

# `trimmedmean/trimmedmean.go`

```go
// Package trimmedmean provides functions to compute symmetric and asymmetric trimmed means,
// helpers for integer slices, and utilities to evaluate the distribution and recommend trimming.
// It includes robust input validation (NaN/Inf checks, trim bounds, result-size checks) and
// diagnostics (skewness, IQR outlier counts).
package trimmedmean

import (
	"errors"
	"fmt"
	"math"
	"sort"
)

// TrimRecommendation contains the diagnostic results and trimming recommendation.
type TrimRecommendation struct {
	Skewness       float64 // Fisher-Pearson adjusted sample skewness
	LowTrim        float64 // recommended proportion to trim from low end (0.0 - 0.5)
	HighTrim       float64 // recommended proportion to trim from high end (0.0 - 0.5)
	NumLowOutliers int     // count using 1.5*IQR rule
	NumHighOutliers int
	Interpretation string
}

// err definitions
var (
	ErrEmptyData         = errors.New("cannot compute trimmed mean: dataset is empty")
	ErrNaNOrInf          = errors.New("dataset contains NaN or Inf")
	ErrInvalidTrim       = errors.New("trim proportions must be between 0 and 0.5 and lower+upper < 1")
	ErrInsufficientAfter = errors.New("trimming removes all or too many observations; reduce trim proportions")
)

// TrimmedMean computes a trimmed mean for a slice of float64.
// - If one trim argument is passed, it is used symmetrically for both ends.
// - If two trim arguments are passed, they are used as (lowTrim, highTrim).
// - Returns error on invalid input or if trimming removes too much data.
func TrimmedMean(data []float64, trims ...float64) (float64, error) {
	// Validation: non-empty
	n := len(data)
	if n == 0 {
		return 0, ErrEmptyData
	}

	// copy to avoid mutating caller's slice
	x := make([]float64, n)
	copy(x, data)

	// Check numeric validity (NaN/Inf)
	for i, v := range x {
		if math.IsNaN(v) || math.IsInf(v, 0) {
			return 0, fmt.Errorf("%w: found at index %d", ErrNaNOrInf, i)
		}
	}

	// Determine trim proportions
	var lowTrim, highTrim float64
	if len(trims) == 0 {
		// default symmetric 5%
		lowTrim, highTrim = 0.05, 0.05
	} else if len(trims) == 1 {
		lowTrim, highTrim = trims[0], trims[0]
	} else if len(trims) >= 2 {
		lowTrim, highTrim = trims[0], trims[1]
	}

	// Validate trim ranges
	if !validTrim(lowTrim) || !validTrim(highTrim) || (lowTrim+highTrim) >= 1.0 {
		return 0, ErrInvalidTrim
	}

	// Sort ascending
	sort.Float64s(x)

	// Calculate number of items to drop from each end using floor(n * trim)
	lowDrop := int(math.Floor(float64(n) * lowTrim))
	highDrop := int(math.Floor(float64(n) * highTrim))

	// Ensure after trimming we have at least one element; prefer at least 2 for mean stability
	if lowDrop+highDrop >= n || n-lowDrop-highDrop < 1 {
		return 0, ErrInsufficientAfter
	}

	trimmed := x[lowDrop : n-highDrop]
	sum := 0.0
	for _, v := range trimmed {
		sum += v
	}
	return sum / float64(len(trimmed)), nil
}

// TrimmedMeanInts is a convenience wrapper that accepts []int.
// It converts to float64 and calls TrimmedMean.
func TrimmedMeanInts(data []int, trims ...float64) (float64, error) {
	if len(data) == 0 {
		return 0, ErrEmptyData
	}
	f := make([]float64, len(data))
	for i, v := range data {
		f[i] = float64(v)
	}
	return TrimmedMean(f, trims...)
}

// EvaluateDistribution analyzes the provided numeric slice and returns a TrimRecommendation.
// It computes:
// - skewness (Fisher-Pearson adjusted sample skewness)
// - counts of lower/upper outliers using the 1.5*IQR rule
// - a recommended trimming (lowTrim, highTrim) based on skewness and outlier counts.
//
// The recommended trims are rules-of-thumb and can be used as defaults for TrimmedMean.
func EvaluateDistribution(data []float64) (TrimRecommendation, error) {
	n := len(data)
	if n == 0 {
		return TrimRecommendation{}, ErrEmptyData
	}

	// Copy & check numeric validity
	x := make([]float64, n)
	copy(x, data)
	for i, v := range x {
		if math.IsNaN(v) || math.IsInf(v, 0) {
			return TrimRecommendation{}, fmt.Errorf("%w: found at index %d", ErrNaNOrInf, i)
		}
	}

	// Basic stats: mean and sample std dev (n-1)
	mean := meanFloat64(x)
	std := sampleStdDev(x, mean)
	if std == 0 {
		// constant data
		return TrimRecommendation{
			Skewness:       0,
			LowTrim:        0.05,
			HighTrim:       0.05,
			NumLowOutliers: 0,
			NumHighOutliers: 0,
			Interpretation: "Data are constant (zero variance); default symmetric 5% trimming recommended.",
		}, nil
	}

	// Compute Fisher-Pearson adjusted sample skewness
	skewness := sampleSkewness(x, mean, std)

	// IQR-based outlier counts
	lowOut, highOut := countIqrOutliers(x)

	// Build recommendation rules using skewness and outlier info
	rec := TrimRecommendation{
		Skewness:        skewness,
		NumLowOutliers:  lowOut,
		NumHighOutliers: highOut,
	}

	absSk := math.Abs(skewness)

	// Basic heuristics (tunable)
	switch {
	case absSk <= 0.3:
		// approximately symmetric
		rec.LowTrim, rec.HighTrim = 0.05, 0.05
		rec.Interpretation = "Approximately symmetric distribution; symmetric 5% trimming recommended."
	case skewness > 0.3 && skewness <= 1.0:
		// moderate right skew
		rec.LowTrim, rec.HighTrim = 0.05, 0.10
		rec.Interpretation = fmt.Sprintf("Moderate right skew (skewness=%.3f); trim more from high end (5%% low, 10%% high).", skewness)
	case skewness > 1.0 && skewness <= 2.0:
		rec.LowTrim, rec.HighTrim = 0.05, 0.20
		rec.Interpretation = fmt.Sprintf("Strong right skew (skewness=%.3f); trim more from high end (5%% low, 20%% high).", skewness)
	case skewness > 2.0:
		rec.LowTrim, rec.HighTrim = 0.05, 0.25
		rec.Interpretation = fmt.Sprintf("Extreme right skew (skewness=%.3f); heavy trim from high end (5%% low, 25%% high).", skewness)
	case skewness < -0.3 && skewness >= -1.0:
		rec.LowTrim, rec.HighTrim = 0.10, 0.05
		rec.Interpretation = fmt.Sprintf("Moderate left skew (skewness=%.3f); trim more from low end (10%% low, 5%% high).", skewness)
	case skewness < -1.0 && skewness >= -2.0:
		rec.LowTrim, rec.HighTrim = 0.20, 0.05
		rec.Interpretation = fmt.Sprintf("Strong left skew (skewness=%.3f); trim more from low end (20%% low, 5%% high).", skewness)
	case skewness < -2.0:
		rec.LowTrim, rec.HighTrim = 0.25, 0.05
		rec.Interpretation = fmt.Sprintf("Extreme left skew (skewness=%.3f); heavy trim from low end (25%% low, 5%% high).", skewness)
	default:
		// fallback
		rec.LowTrim, rec.HighTrim = 0.05, 0.05
		rec.Interpretation = "Unable to determine precise skewness category; default symmetric 5% trimming suggested."
	}

	// Adjust recommendations if many outliers exist on one side
	// If outliers are disproportionately high on one side, nudge trimming more that side.
	if rec.NumHighOutliers > rec.NumLowOutliers && rec.NumHighOutliers >= 5 {
		// bump high trim by 0.05 but keep < 0.5
		rec.HighTrim = math.Min(rec.HighTrim+0.05, 0.45)
		rec.Interpretation += " Detected multiple high-side outliers; increased high-side trimming slightly."
	}
	if rec.NumLowOutliers > rec.NumHighOutliers && rec.NumLowOutliers >= 5 {
		rec.LowTrim = math.Min(rec.LowTrim+0.05, 0.45)
		rec.Interpretation += " Detected multiple low-side outliers; increased low-side trimming slightly."
	}

	return rec, nil
}

// ---------- Helper / internal functions ----------

func validTrim(t float64) bool {
	if t < 0.0 || t >= 0.5 {
		return false
	}
	if math.IsNaN(t) || math.IsInf(t, 0) {
		return false
	}
	return true
}

func meanFloat64(x []float64) float64 {
	sum := 0.0
	for _, v := range x {
		sum += v
	}
	return sum / float64(len(x))
}

// sampleStdDev calculates sample standard deviation (dividing by n-1)
func sampleStdDev(x []float64, mean float64) float64 {
	sumSq := 0.0
	for _, v := range x {
		d := v - mean
		sumSq += d * d
	}
	n := float64(len(x))
	if n <= 1 {
		return 0
	}
	return math.Sqrt(sumSq / (n - 1))
}

// sampleSkewness computes the Fisher-Pearson adjusted sample skewness
// formula: (n / ((n-1)*(n-2))) * sum(((xi - mean)/s)^3)
func sampleSkewness(x []float64, mean, s float64) float64 {
	n := float64(len(x))
	if n < 3 || s == 0 {
		return 0
	}
	sum := 0.0
	for _, v := range x {
		sum += math.Pow((v-mean)/s, 3)
	}
	return (n / ((n - 1) * (n - 2))) * sum
}

// countIqrOutliers returns counts of lower and upper outliers using 1.5*IQR rule.
func countIqrOutliers(x []float64) (lowCount int, highCount int) {
	// create a sorted copy
	y := make([]float64, len(x))
	copy(y, x)
	sort.Float64s(y)
	n := len(y)
	if n < 4 {
		return 0, 0
	}
	// quartiles using simple method (median of halves)
	q1 := median(y[:n/2])
	if n%2 == 0 {
		q3 := median(y[n/2:])
		iqr := q3 - q1
		lowerFence := q1 - 1.5*iqr
		upperFence := q3 + 1.5*iqr
		for _, v := range y {
			if v < lowerFence {
				lowCount++
			} else if v > upperFence {
				highCount++
			}
		}
		return lowCount, highCount
	}
	// odd n: exclude median
	q3 := median(y[n/2+1:])
	iqr := q3 - q1
	lowerFence := q1 - 1.5*iqr
	upperFence := q3 + 1.5*iqr
	for _, v := range y {
		if v < lowerFence {
			lowCount++
		} else if v > upperFence {
			highCount++
		}
	}
	return lowCount, highCount
}

func median(a []float64) float64 {
	m := len(a)
	if m == 0 {
		return 0
	}
	if m%2 == 1 {
		return a[m/2]
	}
	return (a[m/2-1] + a[m/2]) / 2.0
}
```

```go
func main() {

	// Seed RNG for reproducibility
	rand.Seed(time.Now().UnixNano())

	// ----------------------------------------------------------------------
	// Generate 100 integers (right-skewed on purpose)
	// ----------------------------------------------------------------------
	intData := make([]int, 100)
	for i := range intData {
		// mixture to induce skew: 90% N(50,10), 10% high outliers
		if rand.Float64() < 0.9 {
			intData[i] = int(rand.NormFloat64()*10 + 50)
		} else {
			intData[i] = int(rand.Float64()*400 + 200) // outliers
		}
	}

	// Save to CSV so user can check in R
	saveIntCSV("int_sample.csv", intData)

	// Compute symmetric 5% trimmed mean using Go package
	goIntTM, err := trimmedmean.TrimmedMeanInts(intData, 0.05)
	if err != nil {
		panic(err)
	}

	// ----------------------------------------------------------------------
	// Generate 100 floats (right-skewed gamma-like)
	// ----------------------------------------------------------------------
	floatData := make([]float64, 100)
	for i := range floatData {
		// right-skewed exponential-like distribution
		floatData[i] = rand.ExpFloat64()*20 + 10
	}

	// Save for R evaluation
	saveFloatCSV("float_sample.csv", floatData)

	// Compute symmetric 5% trimmed mean in Go
	goFloatTM, err := trimmedmean.TrimmedMean(floatData, 0.05)
	if err != nil {
		panic(err)
	}

	// ----------------------------------------------------------------------
	// Output results
	// ----------------------------------------------------------------------

	fmt.Println("\n======================================================")
	fmt.Println("                 TRIMMED MEAN TESTS")
	fmt.Println("======================================================\n")

	fmt.Printf("Go trimmed mean (integers), symmetric 5%%: %.6f\n", goIntTM)
	fmt.Println("Use the following in R to verify:")
	fmt.Println("    x <- scan('int_sample.csv', sep=',')       # or read.csv")
	fmt.Println("    mean(x, trim = 0.05)\n")

	fmt.Printf("Go trimmed mean (floats), symmetric 5%%: %.6f\n", goFloatTM)
	fmt.Println("Use the following in R to verify:")
	fmt.Println("    x <- scan('float_sample.csv', sep=',')")
	fmt.Println("    mean(x, trim = 0.05)\n")

	fmt.Println("CSV files written: int_sample.csv, float_sample.csv\n")

	// Optional: show trimming recommendation based on distribution analysis
	intRec, _ := trimmedmean.EvaluateDistribution(convertIntsToFloat(intData))
	fmt.Println("Integer sample recommendation:", intRec)
	floatRec, _ := trimmedmean.EvaluateDistribution(floatData)
	fmt.Println("Float sample recommendation:", floatRec)

	fmt.Println("\nDone.")
}

func saveIntCSV(filename string, data []int) {
	f, err := os.Create(filename)
	if err != nil {
		panic(err)
	}
	defer f.Close()

	w := csv.NewWriter(f)
	defer w.Flush()

	for _, v := range data {
		w.Write([]string{fmt.Sprintf("%d", v)})
	}
}

func saveFloatCSV(filename string, data []float64) {
	f, err := os.Create(filename)
	if err != nil {
		panic(err)
	}
	defer f.Close()

	w := csv.NewWriter(f)
	defer w.Flush()

	for _, v := range data {
		w.Write([]string{fmt.Sprintf("%f", v)})
	}
}

func convertIntsToFloat(v []int) []float64 {
	out := make([]float64, len(v))
	for i := range v {
		out[i] = float64(v[i])
	}
	return out
}
```
